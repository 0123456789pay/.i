🤖 Modul AI & RAG

Fitur Utama:

  • AI Engine: Mesin inferensi dengan dukungan RAG
  • Prompt Interface: UI interaktif untuk query AI
  • Project Generator: Pembuatan kode otomatis berbasis requirements
  • RAG Database: 500 file dengan 100.000+ baris pengetahuan

Kategori Pengetahuan:

  • negara - Geopolitik & Negara Asia Tenggara
  • kode - Pemrograman & Development
  • jaringan - Infrastruktur Jaringan
  • perangkat - Hardware & Perangkat Keras

📊 Monitoring Trafik

Modul /trafict menyediakan dashboard monitoring real-time untuk:

  • Total requests dan success rate
  • Average response time
  • Error rate tracking
  • Active connections monitoring
  • Bandwidth usage statistics
  • Endpoint performance tracking

🚀 Deployment

Perintah Publish:

./publish.sh build      # Build ke folder /dist
./publish.sh publish    # Build + Create archive
./publish.sh clean      # Clean dist folder
./publish.sh status     # Show system status

Terminal Commands:

status    - Tampilkan status sistem
build     - Build semua komponen
deploy    - Deploy ke production
merge     - Merge perubahan
help      - Tampilkan bantuan
