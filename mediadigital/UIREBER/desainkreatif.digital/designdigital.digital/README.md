# Design digital - Situs Web Lengkap

## 📁 Struktur direktori

```
designdigital/
├── indeks.php           # Halaman utama dengan masuk
├── papan-bilas.php       # papan-bilas pengelola terindeks
├── logout.php          # Logout pengendali
├── css/
│   └── gaya.css       # lembar gaya utama
├── js/
│   └── utama.js         # skrip-skrip-javascript utama
├── db/
│   └── data.json       # basis-data JSON (para pengguna, halaman, catatan-catatan)
├── filemanajer/
│   └── indeks.html      # berkas manager interface
└── [100+ berkas .html]   # Menu-menu situs design digital
```

## 🔐 masuk Credentials

- **Username:** pengelola
- **sandian:** admin123

## 📄 Fitur Utama

1. **Homepage (indeks.php)** - Landing halaman dengan navigasi lengkap
2. **papan-bilas (papan-bilas.php)** - Panel pengelola dengan:
   - Statistik halaman
   - berkas manager counter
   - Daftar halaman terindeks
   - Akses cepat ke menu situs
3. **100+ Halaman HTML** - Menu penting untuk situs design digital
4. **basis-data JSON** - Menyimpan data para pengguna, halaman, dan catatan-catatan
5. **berkas Manager** - Interface untuk manage berkas

## 🚀 Cara Menggunakan

1. unggah direktori ke peladen PHP
2. Akses `indeks.php` di browser
3. masuk dengan credentials di atas
4. Kelola konten melalui papan-bilas

## 📊 Teknologi

- **Frontend:** HTML5, CSS3, skrip-skrip-javascript
- **Backend:** PHP (sesi-based)
- **basis-data:** JSON berkas-based
- **penyimpanan:** berkas manager sistem
